# Research: MIP Sensor Validation Data (2024-2026 Literature)

## Key Paper: PEDOT-TEMPO-MIP for PFOA Detection
- Source: Environ. Sci. Technol. Lett. 2024
- MIP type: Conductive PEDOT with TEMPO redox mediator
- Target: PFOA
- **Reproducibility: 5.1% RSD across 3 electrodes** (excellent)
- Detection mechanism: Direct electrochemical (no external redox probe needed)
- This is significant because it eliminates the need for solution-phase redox mediators

## Key Paper: MIP + Gold Nanostars for PFOS
- Ultra-sensitive voltammetric sensor
- LOD: 0.04 nM (approximately 0.02 ppt)
- Selectivity validated against common drinking water interferents
- Humic acid and chloride showed minor influence

## Key Paper: μ-MIP Microelectrodes for GenX
- Miniaturized MIP on microelectrodes
- Applied to GenX (HFPO-DA) detection in river water
- Demonstrates that MIP approach works across different PFAS species
- Published in ES&T Letters

## MITRE Technical Report (2025)
- Comprehensive review of MIP-based electrochemical sensors for PFAS
- Confirms:
  - Electropolymerization is the preferred MIP deposition method for sensors
  - Screen-printed electrodes are suitable substrates
  - Key challenge: batch-to-batch quality assessment at industrial scale
  - Standardized manufacture workflows needed for mass production

## Implications for TRACE-1

### Validated Performance
- Sub-ppt detection is achievable with current MIP technology
- Electropolymerization provides good reproducibility (5.1% RSD)
- Multiple PFAS species can be targeted with different MIP formulations

### Key Technical Risks (Updated)
1. **Batch reproducibility at scale** — 5.1% RSD is excellent for lab-prepared electrodes; need to verify this holds with cleanroom-fabricated chips
2. **Matrix effects** — published data shows minor interference from common water components, but need extensive validation in diverse real samples
3. **Template leaching** — residual PFAS template in MIP could cause false positives if removal is incomplete
4. **Long-term storage** — published shelf-life data is limited; need dedicated stability study

### Monitoring Frequency Data
- EPA requires quarterly PFAS monitoring (minimum 4 tests/year per system)
- Systems above trigger levels: quarterly + running annual average
- Systems below trigger: can reduce to triennial after initial monitoring
- Practical need: utilities want weekly/daily monitoring during treatment optimization
- This means 4-365 tests per year per utility, depending on phase
